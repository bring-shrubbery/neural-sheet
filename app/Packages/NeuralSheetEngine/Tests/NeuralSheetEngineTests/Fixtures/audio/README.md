# Audio fixture

`fixture_3chunks_16k.wav` is an excerpt of:

- **Title:** You Drive Me Insane
- **Artist:** Jon Worthy and the Bends
- **Album:** Only A Dream
- **Source:** <https://freemusicarchive.org/music/Jon_Worthy_and_the_Bends/Only_A_Dream/You_Drive_Me_Insane/>
- **Licence:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)

Changes from the original: the first 15 seconds only, downmixed to mono and
resampled from 44.1 kHz to 16 kHz float32. `uv run msl-audio-fixture --source
<original.mp3>` rebuilds it.
