NeuralSheet for iPhone and iPad, sharing the Mac app's packages and engine (design: `docs/design/2026-10-03-ios-app-design.md`).
`make project` regenerates `NeuralSheet-iOS.xcodeproj` from `project.yml` (`brew install xcodegen`); edit the spec, never the generated project.
Build with `xcodebuild -project NeuralSheet-iOS.xcodeproj -scheme NeuralSheet -destination 'generic/platform=iOS Simulator' build` (CMake on PATH, submodules checked out), or open the project in Xcode.
Models live in the app container's `Library/Application Support/NeuralSheet/models` (Settings → Download, or copy a checkpoint there in the simulator); the run tests use the small one when it is there and skip otherwise. With a project open, `SIMCTL_CHILD_NSUnbufferedIO=YES xcrun simctl launch --console-pty booted com.quassum.neuralsheet.ios -autoTranscribe small` imports the bundled take and transcribes it, logging `NeuralSheet run:` lines; `Scripts/make-test-take.py` regenerates the take. Add `-logMeters` to log the meters, the mix, the speed, the loop and the click once a second while the take plays (`log stream --predicate 'subsystem == "com.quassum.neuralsheet.ios"'`, category `meters`).
